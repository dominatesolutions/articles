# Dominate Solutions — 30-Day Social Media Kit

Instagram + Facebook content for **Aug 1 – Aug 28, 2026** — one post every 3 days (10 posts total).

## What's here

| File / folder | What it is |
|---------------|------------|
| `content-calendar.md` | The master plan: schedule, themes, hashtag banks, posting times. |
| `posts/` | 10 ready-to-publish captions (one file per post) with hashtags and image concepts. |
| `graphics/` | The 10 branded post images (1080×1080, Instagram/Facebook square). |
| `SCHEDULING-GUIDE.md` | How to auto-schedule all 30 days so it posts every 3 days on its own. |

## How to use it

1. **Review** the captions in `posts/` — swap in a real testimonial for Post 5 and confirm the offers/CTAs match what you're running.
2. **Grab** the matching graphic from `graphics/`.
3. **Schedule** everything in Meta Business Suite (see `SCHEDULING-GUIDE.md`) — about 20 minutes to set up the whole month.
